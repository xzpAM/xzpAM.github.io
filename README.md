## 🛠️ Local Development (Debug & Preview)

To update profiles, add new publications, or modify the layout, you can run the website locally to preview changes before pushing them to production.

### 1. Prerequisites

Ensure you have Ruby and Bundler installed. (Refer to the official [Jekyll Installation Guide](https://jekyllrb.com/docs/)).

### 2. Run Locally

Clone this repository, navigate to the root directory, and execute:

```bash
bundle exec jekyll serve
```
